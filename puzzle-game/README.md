# Puzzle Game

Meri web puzzle game — ek hi game mein teen puzzles:

- **Sliding Puzzle** — 3x3, 4x4 aur 5x5 sizes
- **Memory Match** — cards flip karke pairs milao (6/8/12 pairs)
- **Word Scramble** — Hinglish hints wale words (Khana / Nature / India categories)

Features: timer, moves counter, best score, jeet par confetti aur sound effects, light/dark mode.

Banaya gaya: 14 Nov 2026 (Muse ke saath)
